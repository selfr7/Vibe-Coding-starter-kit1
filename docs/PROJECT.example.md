# Project Brief（示例）

> 这是一个填好的示例，帮你知道"填成什么样算合格"。
> 正式填写请用 `docs/PROJECT.md`。
> 示例项目：一个极简记账小工具。

## 1. Project Name

项目名称：轻记账

## 2. One-line Description

一句话说明这个产品：打开就能记一笔的极简记账网页，不需要登录。

## 3. Target Users

目标用户：觉得记账 App 都太复杂、只想知道"这个月花了多少"的普通人。

## 4. Problem

用户现在遇到什么问题？想记账但坚持不下来，因为现有 App 步骤太多、要注册、功能太重。

## 5. Solution

产品准备怎么解决？打开网页就能记，输入金额和用途两个信息就完成，数据存在自己浏览器里。

## 6. MVP

第一版必须包含：

- 记一笔：金额 + 用途标签（可选备注），点击保存
- 首页显示本月总支出和最近 20 条记录
- 数据保存在浏览器本地（localStorage），刷新不丢
- 手机上好用（大部分人在手机上记账）

## 7. Not Included

第一版明确不做：

- 注册/登录、多设备同步
- 收入记录、预算、报表图表
- 多账本、自定义分类管理
- 分享、社交功能

## 8. Main User Flow

```text
打开网页
↓
输入金额（自动聚焦）
↓
选一个用途标签（可选）
↓
点「记一笔」
↓
本月总额更新 + 记录出现在列表顶部
```

## 9. Pages

- 首页（记账 + 记录列表 + 本月汇总）——只有这一个页面

## 10. Data / Backend

需要保存哪些数据？记录列表（金额、用途、时间），存在浏览器 localStorage，不需要后端。

## 11. Integrations

第三方服务：无。

## 12. Current Priority

当前最重要的一件事：把「记一笔」做到 3 秒内完成。

## 13. Future Ideas

以后可能做，但现在不要实现：

- 数据导出 CSV
- 月度对比图表
- PWA 离线使用
